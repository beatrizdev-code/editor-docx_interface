**Gerador de Atestado Psicológico**
**🚨 OBS:** Feito especificamente para uma empresa de recrutamento e seleção. 

**Aplicação desktop em Python para gerar automaticamente documentos, a partir de um formulário com interface gráfica. Elimina a necessidade de editar manualmente o documento no Word para cada novo candidato.
**

**Funcionalidades** ⬇️
- Formulário gráfico (customtkinter) com todos os campos que variam de candidato para candidato;
- Geração automática do parágrafo de "Aspectos Gerais" a partir de dados soltos (idade, filhos, experiência, curso, percentuais);
- Validação dos campos obrigatórios antes de gerar o documento;
- Exportação para .docx, pronto para impressão ou envio, mantendo a formatação original (títulos, negrito, layout);
- Nome de arquivo sugerido automaticamente com base no nome do candidato.

**Tecnologias utilizadas** ⬇️
- Python-docx — leitura e escrita de arquivos Word;
- Customtkinter — interface gráfica moderna baseada em Tkinter.
